# Neon Blocks Classic – ikona

Pôvodný vektorový motív neónových blokov bez textu. `neon-blocks-icon.svg` je farebný podklad pre náhľad a ďalšie exporty; nejde o hotový PNG súbor pre Google Play.

Android používa samostatné pozadie, farebné popredie a jednofarebnú vrstvu pre tematické ikony. API 24/25 má vektorovú záložnú ikonu. Tvary maskuje launcher zariadenia. Zdroje sa obnovia cez `node scripts/generate-icons.cjs`; ručne upravené generované súbory sa tým prepíšu.

Motív: azúrový padajúci blok, ružové L, žltý štvorec a fialový spodný rad. Hlavný symbol je v strede plochy 108 × 108 dp.
